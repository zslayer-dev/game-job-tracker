# 시연 영상 대본 (3분 이내)

배포 주소: **https://game-job-tracker.vercel.app**
기준 문서: PRD 1장(한 문장 정의)·2장(문제 정의)·5장(Must·Should·Could), README의 기능·설계 요약.
녹음용 원고(말할 문장만): [demo-narration.md](demo-narration.md)

## 만드는 방식

1. **영상**: Playwright가 배포 주소에서 아래 장면을 순서대로 자동 녹화한다(1280×720, 실제 AI 1회 호출). 장면마다 **목표 길이**에 맞춰 기다리고, 장면 경계 시각을 파일로 남긴다.
2. **음성**: 읽기용 원고를 편하게 읽어 녹음한다. 장면 사이에 1초쯤 쉬면 맞추기가 쉽다.
3. **합성**: 로컬 음성 인식으로 문장별 시각을 뽑아 장면과 짝짓고, 장면마다 음성 속도나 영상 길이를 조절해 합친다.

- 계정 **A** = 관리자로 지정된 본인 계정(일반 창). 계정 **B** = 일반 계정(두 번째 창).
- 자동 녹화에서는 구글 계정 선택 화면을 거치지 않는다(자동화할 수 없음). 2번 장면에서 [구글 계정으로 로그인]을 누르는 동작까지 보여 주고, 구글로 넘어가는 요청은 녹화 스크립트가 막은 뒤 미리 받아 둔 세션으로 목록에 들어간다.
- 브라우저 확인 창(횟수 초기화의 "초기화할까요?")은 녹화 영상에 찍히지 않는다. 화면에는 확인 뒤의 결과 문구가 보인다.
- **녹화 때만 덧입히는 것**(앱 코드는 바꾸지 않음, 녹화 스크립트가 CSS·스크립트로 페이지에 넣는다):
  - **주소 띠**: 화면 맨 위에 현재 주소를 보여 주는 작은 띠(예: `https://game-job-tracker.vercel.app/applications/…`). 주소가 바뀔 때마다 갱신한다. 1번 장면에서 배포 주소가, 10번 장면에서 A와 B가 같은 `/applications/…` 주소라는 게 보이게 하려는 것이다.
  - **이메일 가리기**: 관리자 목록의 이메일은 앞 4글자만 남긴다(예: `zomb•••@gmail.com`). 상단 바의 내 이메일은 흐리게 가린다.
  - **강조**: 9번 장면에서 초기화할 A의 줄을 잠깐 테두리로 강조한다.

## 녹화 전 준비

- **계정 A(관리자, 본인 계정)**: 지원 건·프로필이 없어야 [샘플 데이터 채우기] 버튼이 보인다. 이전 데이터가 있으면 SQL Editor에서 지운다(아래 "정리" SQL의 A 줄).
- **A의 오늘 남은 분석 횟수**: 관리자 화면에서 A의 [횟수 초기화]를 미리 눌러 `0 / 10`으로 만든다(9번 장면에서 `1 / 10` → `0 / 10`이 보이게).
- **계정 B(일반)**: 지원 건이 없어야 10번 장면에서 빈 목록이 보인다. 관리자가 아니어야 한다.
- **AI 권한 모드**: 관리자 화면에서 "전체 허용"인지 확인한다(현재 전체 허용).
- **세션 파일**: 2단계(자동 녹화)를 시작할 때 A·B 각 창의 콘솔에서 내려받는 방법을 따로 안내한다.
- 실제 AI 호출은 녹화 1번당 1회다. **다시 찍을 때마다** 아래 정리 SQL로 A·B 데이터를 지우고, A의 횟수를 다시 초기화한다.

## 녹화 후 정리

SQL Editor에서(A·B의 사용자 ID를 넣어):

```sql
delete from public.applications    where user_id in ('A의-ID', 'B의-ID');   -- 분석 결과도 함께 지워진다
delete from public.profiles        where user_id in ('A의-ID', 'B의-ID');
delete from public.ai_usage        where user_id in ('A의-ID', 'B의-ID');   -- 선택: 시연으로 쓴 호출 기록
delete from public.ai_quota_resets where user_id in ('A의-ID', 'B의-ID');   -- 선택: 시연으로 남은 초기화 기록
```

- **녹화 1번마다 `admin_actions`에 초기화 기록(`quota_reset`)이 2건 쌓인다**(준비 단계에서 A 초기화 1건 + 9번 장면 1건). 운영 감사 기록이라 지우지 않는다.
- AI 권한 모드가 "전체 허용"인지 다시 본다.
- 세션 파일은 2단계 스크립트가 읽은 즉시 지운다. 내려받기 폴더에 남은 것이 없는지 확인하고, 두 창에서 로그아웃한다(로그아웃하면 그 세션의 갱신 토큰이 폐기된다).
