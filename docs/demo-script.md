# 시연 영상 대본 (3분 이내)

배포 주소: **https://game-job-tracker.vercel.app**
기준 문서: PRD 1장(한 문장 정의)·2장(문제 정의), README의 기능·설계 요약.

---

## 녹화 전 준비

- **계정 A**(일반 창): 지원 건·프로필이 하나도 없는 상태. 이전 검증 데이터가 있으면 [s5-checklist.md](s5-checklist.md) 5장 SQL로 먼저 지운다. 그래야 [샘플 데이터 채우기] 버튼이 보인다.
- **계정 B**(시크릿 창 또는 다른 브라우저 프로필): 미리 로그인해 두고 창을 옆에 숨겨 둔다.
- A의 오늘 남은 분석 횟수가 1회 이상인지 확인한다(분석 1회 사용).
- 브라우저 확대 110~125%, 다크 모드 통일, 북마크바·다른 탭·이메일 알림 숨기기. 화면에 계정 이메일이 보이면 편집 때 가린다.
- 실제 AI 호출은 약 5초 걸린다. 기다리는 동안 할 말을 대본에 넣어 두었다.
